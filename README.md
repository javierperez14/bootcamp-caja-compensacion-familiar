## Dominio

Las **Cajas de Compensación Familiar** son entidades colombianas que administran el subsidio familiar y ofrecen servicios sociales a trabajadores y sus familias. Las entidades principales del dominio son:

| Entidad | Descripción |
|---------|-------------|
| `Benefit` | Catálogo de beneficios ofrecidos a afiliados |
| `Affiliate` | Trabajadores afiliados y sus familias |
| `Employer` | Empresas aportantes al sistema |
| `Service` | Servicios prestados (salud, recreación, vivienda) |
